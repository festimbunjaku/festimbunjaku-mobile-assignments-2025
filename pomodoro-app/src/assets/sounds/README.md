# Sound Assets

## Required Files

### alarm.mp3

Add your alarm sound file here named `alarm.mp3`

You can:

1. Download a free alarm sound from [freesound.org](https://freesound.org)
2. Use a system sound
3. Create your own alarm sound

The sound should be:

- Short (2-5 seconds recommended)
- Pleasant but noticeable
- MP3 or WAV format

For now, you can skip this and the app will log an error but won't crash.
